**Expense** **Tracker** **Console** **Application**

**Description**

A simple Python-based Expense Tracker that allows users to input product names and their corresponding prices. The program stores all entries in a dictionary, calculates the total expenses, and displays a final summary of all items purchased.

**Features**

Add multiple expense items

Store item names with prices using a dictionary

Automatically calculate total expenses

Display a clean expense summary

Exit input mode using "No more items"

**Requirements**

Python 3 installed

**How** **to** **Run**

python3 expense_tracker.py
