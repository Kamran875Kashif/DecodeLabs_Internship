**Password** **Generator** **Console** **Application**

**Description**

A simple Python-based Password Generator that creates secure random passwords using Python’s secrets module. The user can specify the password length, and the program generates a strong password using letters, digits, and special characters. It also supports generating multiple passwords in a single session.

**Features**

Generates cryptographically secure passwords using secrets

Custom password length input

Uses uppercase, lowercase, digits, and symbols

Option to generate multiple passwords in one run

Input validation for menu selection

**Requirements**

Python 3 installed

**How** **to** **Run**

python3 password_generator.py
