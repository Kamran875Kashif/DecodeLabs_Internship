**Guess** **the** **Correct** **Answer** **Game** (**Quiz** **Game**)

**Description**

A simple Python-based quiz game where the user answers three general knowledge questions. Each correct answer awards 1 point, and the final score is displayed at the end of the game.

**Features**

Interactive console-based quiz

3 general knowledge questions

Automatic score calculation

Different result messages based on performance

Simple menu to start or exit the game

**Requirements**

Python 3 installed

**How** **to** **Run**

python3 quiz_game.py
