**Todo List Console Application
**

**Description**

A simple command-line Todo List application built with Python. The program allows users to add tasks, store them in memory using a list of dictionaries, and display all saved tasks. Each task is assigned a unique ID automatically.

**Features**

Add multiple tasks
Automatically assign task IDs
Display all saved tasks
Menu-driven console interface
Exit task entry mode using the end command

**Requirements**

Python 3 installed

**How to Run
**
python3 todolist.py

Replace todolist.py with the actual filename if different.
